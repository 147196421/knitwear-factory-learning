零基础先记住这一句

纸上从下往上读，数字要横竖分开看。

横向的“支”主要管宽度，纵向的“转”主要管高度。每次只看一个衣片：先找开针，再沿轮廓向上追踪加针、收针、夹位、领窝和结束。

第一步

先认整张纸的五个区域

不要一上来就钻进衣片中间的小数字。

  1. 身份尺码、日期、版本。先确认没有拿错款或旧版。
  2. 尺寸左侧表格通常是英寸尺寸，不是针数。
  3. 密度与组织横密、纵密、单边、罗纹、四平、提花等。
  4. 衣片版图前幅、后幅、袖片以及领口局部图。
  5. 纱线与后整颜色、股数、用量、缝盘、洗水、拉度等。
老师提醒

成衣照片只能帮助辨认款式外观；真正算针数，要看尺寸、密度和衣片旁的工艺数字。

第二步

把纸上的行话翻译成白话

先理解功能，不急着背全部术语。

支

放在衣片轮廓旁时，通常表示当前针数。例如“开55支”就是起织时使用约55个针位。

转

纵向工艺计数。它帮助决定高度，但不能未经确认就等同于软件行号或机头单程。

开

开始这片织物时的开针数。例如袖片“开55支”。

齐织

在当前工作针范围内继续织若干转，通常不改变两边宽度。

夹位／夹圈

就是衣身腋下到肩部的袖窿区域；两边通常从这里开始收窄。

衫脚／袖咀

分别指衣身下摆和袖口。常用罗纹或其他有弹性的组织。

领贴

领口边条。它的高度、组织、开针和收口要独立看，不要混进衣身针数。

停针

针上的线圈暂时保留，但这部分暂时不继续织；它不等于让线圈直接脱落。

X+Y+Z／X-Y-Z怎么读

X每隔多少转＋或－Y每次每边多少支＋或－Z重复多少次

在这两张图采用的写法中，5+1+3读成“每隔5转，左右每边加1支，共做3次”。左右合计增加：1×3×2＝6支。这里的“×2”来自左右两边；单边说明时不能机械乘2。

后幅

163支 → 约94转
  1. 从下方“163支”开始，先看下摆和起底说明。
  2. 直身段宽度基本稳定；“45转”等写在段落旁的数字主要控制高度。
  3. 到夹位后，轮廓两边向内，旁边的减针组决定每次收多少。
  4. 后领通常较浅，但仍以领口处数字为准。

前幅

图旁160支 → 约95转
  1. 先从图形底部“160支”以及下面的开针说明核对起点。
  2. 身段向上到夹位，先完成两侧收窄。
  3. 前领比后领更深，所以较早把中间领位分开。
  4. 左右肩会成为两个工作区；领窝和肩斜可能交叉进行。

袖片

55支 → 111支，约59转
  1. 从袖口“开55支”开始。
  2. 袖身两边逐组加针，所以轮廓逐渐变宽。
  3. 到上部约111支后进入袖山，不再继续加宽。
  4. 袖山两边分组停针／收窄，最后完成顶部。

图纸2袖片完整算例

袖口55支，怎样加到111支，再收到17支

袖身加针

纸上写法左右共加工作针
开始—55
5+1+31×3×2＝661
1+1+71×7×2＝1475
2+1+141×14×2＝28103
4+1+41×4×2＝8111

总验算：55＋6＋14＋28＋8＝111支。

袖山停针

纸上写法左右共停工作针
开始—111
1-2-32×3×2＝1299
1-3-73×7×2＝4257
1-5-45×4×2＝4017

总验算：111－12－42－40＝17支。

最重要的发现：公式里的第一个数字控制“隔多少转做一次”，所以它影响高度和斜度；第二、第三个数字决定一次多少支、做几次，所以决定总共增减多少支。

第五步

每一片都用这六问检查

回答不出来的地方先圈出来，不要猜。

  1. 这是什么片：前幅、后幅还是袖片？
  2. 从哪里起织，开多少支？
  3. 下摆／袖口是什么组织，织多少转？
  4. 哪些段针数不变，哪些段在加针或收针？
  5. 最后到多少支、多少转，左右合计能不能反算回来？
  6. 哪些是照片确认，哪些仍需原纸、样片或师傅确认？
学习边界

这页教你读懂工艺逻辑，不生成慈星上机程序，也不校验纱嘴、移圈、摇床、度目、罗拉或撞针风险。真正生产前还要有清晰原纸、纱线、样片密度、制版文件和试织确认。
