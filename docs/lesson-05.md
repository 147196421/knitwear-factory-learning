# 第5课：单边、1×1罗纹、四平概念怎样分别成圈

## 本课只解决一个问题

同样写“8个针位”，为什么换一种组织以后，布的厚度、弹性和尺寸会改变？

答案是：针数只告诉你准备了多少横向针位，组织还决定前针床、后针床中的哪些针参加工作，以及线圈怎样排列。针数相同，不代表成品宽度相同。

## 打开动画以后怎样学

1. 先选“单边”，按一次“下一针”，只观察前床。
2. 连续按到第8针，再按一次，确认第2行机头已经反向。
3. 切换“1×1罗纹”，观察相邻针位怎样在前床、后床之间交替。
4. 切换“四平概念”，观察前后床怎样分行参与。
5. 最后做页面底部的一分钟检查。

动画固定使用4行、每行8个逻辑针位。它把真实机器的连续机械动作拆慢，只用于理解针床分配，不是生产程序。

## 先认识前针床与后针床

电脑横机有相对布置的前、后针床。织针在哪一床工作，会影响线圈朝向和组织结构。

- 页面上方标“后床”，下方标“前床”。
- 橙色织针是这一刻正在工作的针。
- 蓝色织针是这一行按当前组织应当参加工作的针。
- 灰色织针在当前简化模型中不工作。
- 后床形成的线圈使用虚线，前床形成的线圈使用实线；这样不用只靠颜色也能分辨。

## 单边

白话：先让一边针床连续织。

本模型中8个针位全部由前床依次成圈，后床休息。常见单边织物正反面外观不同，通常比双面组织薄，边缘也比较容易卷。

纸上看到“单边”，先把它当作组织名称。它不是加针公式，也不是“只织一支针”。实际制版仍要确认针距、纱线、度目、罗拉和具体程序。

## 1×1罗纹

白话：一个正面线圈、一个反面线圈交替排列。

页面用前床第1个逻辑针位、后床第2个逻辑针位交替表示“前1、后1”的重复关系。罗纹横向拉开后通常更容易回弹，所以常用于下摆、袖口和领口。

“1×1”描述组织重复，不等于工艺单中的`1+1`加针，也不能把它直接读成总针数翻倍。

## 四平概念

白话：先把它理解成前、后针床都参与的一类双面结构。

网站用“前床一行、后床一行”交替的简化动作，让初学者看见双面结构为什么往往更厚、正反面更接近。这个动作只是一种空间解释，不是慈星机器可直接使用的四平程序。

“四平”的行业叫法和具体走针可能随地区、师傅、工厂与控制系统不同。正式制版前必须取得该厂的组织定义、样片或程序说明，不能只按中文名称猜走针。

## 为什么组织变化后必须重做密度

密度不是机器永久不变的属性。它至少会受这些因素影响：

- 组织；
- 纱线原料与支数；
- 合股数；
- 度目；
- 罗拉牵拉；
- 洗水与后整理状态。

假设单边试片量得横密9支/英寸，这个9只能先用于条件相同的单边区域。下摆改成1×1罗纹以后，即使起针数看起来相近，也不能直接宣布下摆宽度等于`针数÷9`。正确做法是织对应罗纹试片，按同一测量状态重新量密度。

## 这一课怎样验收

能用自己的话说出下面四句，才算学会：

1. 针数相同不代表布宽相同。
2. 单边模型只让前床工作；1×1罗纹让前后针位交替。
3. 组织名称和加减针公式不是一回事。
4. 罗纹和身段不能默认共用一套密度。

## 当前模型的边界

- 没有模拟完整针舌开合、三角轨迹、沉降片和纱嘴避让。
- 没有给出真实度目、罗拉、速度和纱嘴编号。
- “四平概念”只解释前后床参与，不定义具体生产走针。
- 页面中的8针和4行是教学数量，不对应真实衣片幅宽或工艺单转数。
- 正式上机必须经过制版、撞针风险检查、空车检查、试织和尺寸复核。
