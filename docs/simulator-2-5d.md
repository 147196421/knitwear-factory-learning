# 第4课：横机动作实验室

## 6.0版整机教学复原

- 默认先显示参考实拍CX2-52C-U外观绘制的整机视角，再切换到内部原理特写。
- 整机和内部视角共用4行×8针×4阶段＝128步状态，不是两段互不相关的视频。
- 整机中的机头、纱嘴、纱线路径、当前编织段和织片长度会随步骤同步变化。
- 采用“动作真实优先”：外观用于建立部件位置感，内部特写用于看清成圈；不追求未经厂家图纸验证的精确机械尺寸。
- 本模型不是厂家官方模型、数字孪生、控制器仿真或可上机程序，不校验撞针风险。

## 这一课解决什么问题

工艺单告诉我们要织多少针、多少段，但初学者还看不见机器里“一根针怎样形成一个新线圈”。这一课把复杂实机缩减为8根教学针，让动作可以暂停、后退和逐步检查。

## 四层怎样使用

1. **2D针位**：先分清工作针、新增针和停织针。
2. **2.5D成圈**：播放机头左右往返，观察纱嘴和当前针。
3. **前后针床**：旋转模型，切换单边、1×1罗纹和四平概念针位。
4. **慈星对应**：区分哪些内容来自铭牌、哪些只是同系列线索、哪些仍等待确认。

## 2.5D模型的时间轴

模型共4行，每行8针，每针拆成4个阶段，所以共有：

`4行 × 8针 × 4阶段 = 128步`

第1、3行从左向右；第2、4行从右向左。这个交替方向用来帮助理解横机机头往返，但工艺单“转”的计数方式不能据此直接固定换算。

每根针的四步是：

1. 针上升，针钩穿过旧线圈，针舌打开。
2. 纱嘴来到针位，把新纱垫入针钩。
3. 针下降，针舌合上，旧线圈越过针头脱下。
4. 新纱被拉成新线圈，织片受到向下牵拉。

## 为什么叫2.5D

画面使用有前后深度的针床、机头、纱嘴和织片，但核心动作仍沿清楚的教学平面显示。这样比装饰性3D更容易确认当前是第几针、哪一个阶段。

## 前后针床模型的边界

- 单边：用前床工作、后床休息解释最基本的单面成圈。
- 1×1罗纹：用前后床交替针位解释“前1针、后1针”。
- 四平：目前只显示前后床都参与的概念；具体针法名称、三角路径和程序写法必须按实际地区习惯、控制系统和制版软件确认。

## 不能把动画当成什么

- 不是慈星程序文件。
- 不是控制屏真实程序行回放。
- 不包含完整三角走针、选针时序、纱嘴避让、移圈和摇床路径。
- 不计算度目、罗拉牵拉力或纱线张力。
- 不校验撞针风险。

实际操作必须在安全停机确认、设备资料核对和现场指导条件下进行。
