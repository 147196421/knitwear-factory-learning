## 型号的谨慎解释

- 52通常指52英寸名义编织幅宽。
- CX2在同系列产品资料中通常对应双编织系统。
- 5/7是5G／7G多针距配置线索，不能推导为所有5针和7针工艺都可直接通用。
- C-U可与同系列资料中的穿线板／起底配置相联系，但资料中的完整型号存在CX2-52EC-U写法，与实拍CX2-52C-U不完全相同。

因此，控制系统、针板、纱嘴数量、最高速度、支持的上机文件格式及具体起底结构，不能仅凭同系列宣传资料写成这台实机的确定配置。

## 购买核对清单

购买时不能只写“慈星CX2”。合同或配置单至少应明确：

- 完整型号和出厂配置。
- 针距／多针距规格及实际适用纱线、组织范围。
- 名义和可用编织幅宽。
- 编织系统数。
- 控制系统品牌、版本及升级政策。
- 针板、纱嘴、起底和牵拉配置。
- 制版软件名称、授权方式、培训和文件兼容性。
- 安装条件、保修、售后网点、易损件和备件。
- 用计划生产的纱线和款式做现场试织、洗水与尺寸复核。

二手机还要检查维修记录、针板和机头磨损、报警记录、电气与伺服状态。铭牌日期和外观不能代表实际机况。
