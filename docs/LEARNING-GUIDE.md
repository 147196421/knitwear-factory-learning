# 零基础学习说明与模拟路线

## 这套课程是给谁的

这是一个个人自学项目。学习者没有毛织行业基础，准备从看懂工艺单开始，逐步学习电脑横机原理、制版、试片和设备筹备。

课程统一用“有经验的毛织工艺老师带一个完全零基础学习者”的方式讲解。老师不默认学习者认识术语，也不会只给结论。

## 每一个知识点怎样讲

每课固定走六步：

1. **先看目标**：这一段最后想织成多宽、多长或什么组织。
2. **看纸上写法**：指出工艺单上的数字、符号和位置。
3. **翻译成白话**：例如“左右两边各加1支，共增加2支”。
4. **看机器原理动作**：哪些针工作、哪些针停织、机头向哪边走。
5. **逐步播放**：一次只发生一个动作，可以后退和重来。
6. **反算检查**：用起始针数、每边变化量和次数算回最后总针数。

## 现有课程够不够

现有三课只够完成第一层入门：知道工艺单区域、看懂最基础的加针／停针、把尺寸和密度换算成针数／转数，并知道前幅、后幅、袖片通常从哪里读。

它还不够让学习者独立制版或直接开机生产。至少还要依次学完：

1. 线圈是怎样形成的，前床和后床分别做什么。
2. 1×1罗纹、单边、四平的针床分配和外观区别。
3. 纱嘴、度目、罗拉、副罗拉、起底板分别影响什么。
4. 加针、收针、停针、移圈和摇床的区别。
5. 怎样从尺寸、样片密度和洗水结果制作完整吓数。
6. 与实际控制系统匹配的制版软件和文件格式。
7. 试片、洗水、测量、修改和常见异常排查。

## 参考资料和课程示例是什么关系

课程不是任何一张真实工艺单的完整生产复刻。网页只录入照片中能够核验的少量针数和转数，其余轮廓变化是重新构造的教学模型；不能据此直接制版上机。

这样做有两个原因：一是保护私人和生产信息，二是避免在纱线、密度、组织、洗水和系统都未确认时，把某一张单上的数字误教成通用标准。

## 能不能模拟真实电脑横机逐行织出来

可以，但应分四层制作。

### 第1层：准确的2D针位动画

显示工作针、新增针、停织针以及左右总针数。现在网站的56支→112支和112支→18支属于这一层。它最适合学习工艺计算。

### 第2层：2.5D逐行成圈动画

画面显示：

- 机头从左向右，再从右向左运行；
- 纱嘴跟随机头经过工作区；
- 针上升、针舌打开、垫入新纱、旧线圈越过针舌并脱圈；
- 新线圈形成，织片向下增长一行；
- 可以暂停、慢放、逐针和逐行查看。

这一层会比纯3D更容易看清“这一针到底发生了什么”，应该优先制作。

### 第3层：前后针床3D

3D用于解释空间关系：前床、后床、前后线圈、1×1罗纹、四平、移圈和摇床。画面可以旋转和剖开，但针位、方向和动作必须与2D模型使用同一份数据。

### 第4层：实际机型与制版文件对应

取得控制系统、制版软件版本、针板配置和获准学习的测试文件后，再把程序行、选针、纱嘴、度目和罗拉设置与模拟画面对应。此阶段之前，动画只能教原理，不能当作可直接上机的程序，也不能校验撞针风险。

## 建议的制作顺序

下一步先完成第4课“1×1罗纹、单边、四平”，同时制作第一个2.5D小实验：只用少量针演示机头左右往返，以及单边组织的一行新线圈怎样形成。确认学习者看懂后，再扩展到前后针床3D、移圈和摇床。

这个顺序的重点不是让画面看起来最炫，而是让每一个动画都能回答三个问题：哪根针在动、纱线在哪里、动作后总针数或线圈结构发生了什么变化。
