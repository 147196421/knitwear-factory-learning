# 电脑横机通用学习资料索引

复核日期：2026-09-13。

## 使用原则

- 只把公开资料当作概念依据和进一步阅读入口，不复制整篇文章、原图或视频。
- 课程页面中的文字与示意图均为本项目重新组织、重新绘制。
- “行业通用原理”可以跨品牌帮助理解；软件按钮、程序格式和机器参数不能跨品牌照搬。
- 外部资料与现场手册冲突时，以拟购机器的合同、随机手册、厂家培训和安全试织为准。

## 主动排除

- 未经授权上传到文库、网盘或论坛的整本说明书。
- 宣称“所有国产横机通用”的具体按键教程。
- 无法确认机型、软件版本或发布者身份的视频参数。
- 要求绕过安全限制、拆除防护或带电调整的内容。
