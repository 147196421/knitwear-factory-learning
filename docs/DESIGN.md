# 课程网站设计与交互规范

## 教学目标

这个网站不是产品宣传页，而是给完全零基础学习者使用的“互动工艺手册”。每个页面只解决一个问题，并让学习者能看到动作发生、数字变化和反算结果。

## 信息架构

| 页面 | 只回答的问题 | 主要交互 |
| --- | --- | --- |
| 工艺单地图 | 一张吓数纸分哪几块 | 点击区域高亮 |
| 针数变化 | 加针／停针怎样一步步改变针位 | 时间轴播放与单步控制 |
| 尺寸换算 | 英寸怎样换成针数和转数 | 滑块、输入和实时公式 |
| 织片顺序 | 前幅、后幅、袖片从哪里读 | 选择织片、分段播放 |
| 我的机器 | 照片能确认什么、还缺什么 | 证据状态和现场清单 |

## 视觉规则

- 使用白色纸张、深蓝墨水和淡蓝方格，接近工艺手册与针织方格纸。
- 深蓝表示当前工作和稳定结构，橙色表示本次新增或需要特别留意的变化，灰色表示停织，绿色只用于确认成功状态。
- 重要数字使用等宽字体，方便比较前后变化。
- 手机端把侧栏改为横向导航，按钮保持足够大的点击区域。
- 不用无意义渐变、发光和装饰性仪表盘。

## 2D与3D的选择

当前加针、停针、尺寸换算和织片阅读使用2D。原因是这些课程的重点是准确看到针数、左右对称、重复次数和上下顺序，2D更容易逐格核对。

后续讲前后针床、翻针、搬针、移床／摇床时再使用简化3D或可旋转剖面，因为这些动作需要理解前后、左右和线圈转移关系。3D模型必须标明：

1. 是概念模型还是按某台机器结构建立。
2. 哪些零件和运动被简化。
3. 不能把动画参数直接作为上机程序。

## 内容更新检查

- 新术语是否同时解释纸面含义和机器动作。
- 每个公式是否从起始总针数验算到结束总针数。
- 推断是否标明证据状态。
- 页面是否只增加一个核心难点。
- 手机和电脑是否都能操作。
- 是否同步更新讲义、进度与AI交接文档。

## 设计能力来源

- `frontend-design`：已内置，用于形成符合毛织工艺、方格纸和车间学习语境的独特视觉，而不是套通用SaaS模板。
- `UI UX Pro Max`：来源为 `nextlevelbuilder/ui-ux-pro-max-skill`，用于生成／核对颜色、排版、响应式、触控和无障碍设计系统。

选用外部Skill不等于照抄推荐结果。发生冲突时，依次服从：真实教学需求、项目既有设计规范、可访问性与正确性、外部Skill建议。

## 第4版设计决策

UI UX Pro Max第一次检索把“零基础教育”匹配成儿童应用，推荐卡通字体和蓬松元素，经人工判断不适合成年人职业培训，因此没有采用。缩窄为“成人职业培训、工业工具”后，采用了其中的Swiss式网格、深蓝技术色、清晰状态、44像素触控区和低强度动作反馈。

本项目仍保留自己的行业特征：背景取自针织方格纸，橙色对应新发生的针位变化，顶部学习条同时回答“学到哪里、这页做什么”。不采用通用营销页的Hero、功能卡片和重复CTA结构。
