# 第4课：从图纸到衣片——逐转看懂横机怎样形成轮廓

## 本课学完要会什么

这节课不是让你背按钮，而是先建立一条完整思路：

1. 图纸上的竖向数字控制“织多高”，通常用转数表示。
2. 图纸上的横向数字控制“织多宽”，通常用支数表示。
3. 每完成一转，横机机头换一个方向继续运行。
4. 工作针增加，衣片逐渐变宽；工作针减少或停织，衣片逐渐变窄。
5. 前幅、后幅、袖片的轮廓不同，是因为各阶段的工作针范围不同。

## 第一次打开动画怎样操作

进入第4课后，保持第2层“2.5D成圈”，再选择“图纸→衣片”。严格按下面顺序操作：

1. 选择图纸1或图纸2。
2. 选择前幅、后幅或袖片。
3. 按“从零开始”。
4. 先按一次“下一转”，观察机头方向、当前针数和纸上进度。
5. 连续再按一次“下一转”，确认机头方向已经反转。
6. 按“播放到下一阶段”，只学完当前阶段，停下来读老师说明。
7. 点阶段按钮，直接跳到身段、夹位、领肩或袖山。
8. 最后才按“播放到完成”，看完整轮廓。

不要第一次就快速播放到底。初学时应当“看一转、读一句、核对一次”。

## 两个方向为什么看起来相反

纸上的衣片通常把起底画在下面，把肩领或袖山画在上面，所以阅读方向是从下往上。

真实横机的针床在上方。新织成的一转留在针床附近，已经织好的部分由牵拉机构逐渐带到下方。因此：

- 纸上：衣片从下往上读。
- 机器：衣片从针床向下挂。
- 它们描述的是同一片织物，只是观察方向不同。

## 什么是“支”

在衣片轮廓旁边，“163支”通常表示这个横向工作区大约使用163个针位。它首先是针数概念，不是厘米，也不是纱线粗细。

如果本转为163支、下一转还是163支，机器仍在织，只是轮廓宽度暂时不变。如果从163支变成161支，说明工作区大约减少2支；如果左右对称处理，常见理解是左右各变化1支，但必须以原工艺写法确认。

“支”也可能出现在纱线规格中，那时可能表示纱支，不能与衣片针数混用。

## 什么是“转”

“转”表示纵向编织进度，但不同工厂、组织、控制系统对计数口径可能不同。不能未经确认就断言：

- 1转一定等于机头一个单程；
- 1转一定等于程序中的1行；
- 罗纹、单边、四平都用完全相同的换算。

网站把“转”作为工艺阅读单位，并用一次左右方向变化帮助理解机头往返。正式制版时还要根据实际软件和程序结构核对。

## 身片六个阶段

### 1. 起底与下摆罗纹

白话：先让线稳定挂住，再织出衣服底边。

纸上通常要找：开针多少支、下摆多少转、使用什么罗纹、是否转针、罗纹度目。

机器大致做：起底、牵拉、前后针床按罗纹组织工作。动画只显示宽度和高度，不模拟完整起底板动作。

检查方法：先记住开针数，这是整片衣片的第一个横向基准。

### 2. 身段直织

白话：宽度基本不变，继续把衣身织高。

纸上通常要找：身段总转数、身段支数、组织、度目、纱嘴和颜色变化。

机器大致做：机头持续左右往返，相同工作针范围不断形成新线圈。

关键认识：针数不变不代表没有动作；每一转都在增加衣片长度。

### 3. 夹位分段收针

白话：到了腋下，衣片开始向肩部变窄。

纸上通常会出现多组“隔几转、收几支、做几次”的写法。每组都要分别计算左右变化，再核对剩余针数。

机器大致做：左右边缘部分针位逐步退出当前工作区，中间继续编织。

当前动画只用平滑教学轮廓表示变窄，因为参考照片中的完整夹位收针组数还不能可靠辨认。

### 4. 上胸直织

白话：夹位收窄后，保持较窄宽度再织一小段高度。

这段高度影响袖笼和肩领位置，不能只看最终总转数。正式验算要把下摆、身段、夹位、上胸、肩领各段转数相加。

### 5. 前领／后领与左右肩

白话：中间不再连成一整排，领口把工作区分成左肩和右肩。

前领通常比后领深，所以前幅更早开领或领窝变化更明显。具体做法可能包含收针、停针、局部编织或其他程序动作。

动画在领部把一条线拆成左右两段，表示中间领位打开；这不是完整的纱嘴调度或分区程序。

### 6. 肩部收针与结束

白话：完成最后肩宽和肩斜，然后结束这片。

纸上要核对左右肩是否对称、肩斜总针数、剩余针数以及所有阶段转数合计。动画目前只确认总转数节点，不虚构看不清的肩斜明细。

## 袖片四个阶段

### 1. 袖口罗纹

以较少针数起针，形成贴近手腕且有弹性的袖口。

### 2. 袖身分段加针

袖子越往上通常越宽，所以左右两边按若干转间隔逐步增加工作针。验算公式是：

`结束针数 = 开针数 + 每边每次增加数 × 次数 × 2`

如果存在单边特殊变化或花型循环限制，不能机械乘2。

### 3. 袖山分段收针

到腋下后开始迅速变窄，使袖山与前后幅夹圈配合。这里通常不是简单直线，常由多组不同节奏的收针或停针组成。

### 4. 袖山顶与结束

完成中间剩余工作针并收尾。必须把袖山每组左右变化相加，检查最终剩余针数是否与工艺单一致。

## 动画中三种信息级别

### 照片可辨认节点

表示当前显示的开针数或总转数来自照片中相对清楚的数字，但仍建议用原纸近照复核。

### 教学推演过程

表示阶段位置或中间针数是为了帮助理解而生成的插值，不代表真实生产节奏。

### 等待确认

表示必须取得更清晰原纸、制版软件或机器资料后才能继续。AI不得自行补全。

| 图纸1 | 开163支，约94转 | 开163支，约95转 | 开55支，约59转，上部约111支 |
| 图纸2 | 开154支，约79转；身段旁见166支 | 开150支，约77转；身段旁见162支 | 开55支，约73转，上部约111支 |

这些数字足够学习“宽度和高度如何共同形成轮廓”，但不足以制作生产程序。还缺少每一组加减针、停针、肩斜、领窝、组织、度目、罗拉、纱嘴和安全路径。

## 自己验收这一课

完成下面五项才算真正看懂：

1. 能指出纸上和机器画面的阅读方向为什么相反。
2. 能解释针数不变时机器为什么仍然在织。
3. 能说出身片为什么在夹位变窄、在领部变成两个工作区。
4. 能说出袖片为什么先加宽、后在袖山收窄。
5. 能区分“照片可辨认节点”和“教学推演过程”，不把动画直接当成上机程序。

## 下一次补拍资料时怎样拍

在不包含私人或商业敏感信息的前提下，每个衣片分别拍：

1. 完整轮廓一张，用来确认整体方向。
2. 下摆／袖口数字近照一张。
3. 夹位或袖山全部加减针组近照一张。
4. 领窝与肩斜近照一张。
5. 密度、组织、纱线栏近照一张。

照片应正对纸面、四角完整、光线均匀、没有手指遮挡。款号、商业名称、联系方式、机器序列号和生产文件名应在上传前遮住。
