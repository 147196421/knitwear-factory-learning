# 第1课：先看懂“针”和“转”

## 本课目标

用图纸2照片中能够反算闭合的袖片数据，理解为什么袖口从55支增加到袖身111支，以及袖山最后为什么剩17支。

## 两个最基础单位

- 支：在织片图中通常表示针数／正在使用的针位。
- 转：织片纵向的工艺行数或循环次数。

“支”也可能出现在纱线支数里，例如2/18支纱，因此必须看所在区域。

## 加针公式

在本项目采用的教学记法中，`5+1+3` 表示每5转、每边加1支，共做3次。

不同来源和制版系统可能使用不同排列顺序，或把“每边”另行注明。第一次接触新工艺单时，必须先确认记法，不能只看三个数字就直接上机。

两边总共增加：1×3×2=6支。

袖片验算：

1. 开55支。
2. `5+1+3` 后为61支。
3. `1+1+7` 后为75支。
4. `2+1+14` 后为103支。
5. `4+1+4` 后为111支。

## 停针公式

在本项目采用的教学记法中，`1-5-4（停针）` 表示每1转、每边停5支，共做4次。停针并不等于让线圈脱落，而是暂时不继续编织这些针位。实际订单仍要先确认本厂记法和“左右同时／单边执行”的规则。

### `1-1-2`三个数字分别是什么

先不要把它当成`1−1−2`的普通减法。按本课采用的记法，它是三个连续指令：

1. 第一个`1`：动作间隔——每隔1转执行一次。
2. 第二个`1`：每次数量——每次每边停1支。
3. 第三个`2`：重复次数——这一组动作共做2次。

如果开始有20支工作针，而且左右两边合并计算：

- 开始：20支。
- 第1次：左边停1支、右边停1支，`20−1×2＝18支`。
- 第2次：左右再各停1支，`18−1×2＝16支`。
- 整组总变化：`1支×2次×2边＝4支`，所以`20−4＝16支`。

同样，`1+1+2`就是每隔1转、每边加1支、做2次；左右合计增加4支。

这里的“乘2”来自左右两边，不是公式永远固定要乘2。若工艺图只计算一边，或明确要求左右分开执行，就只按那一边计算。新工艺单必须先确认本厂的记法。

袖山验算：

1. `1-2-3`：每边停6支。
2. `1-3-7`：每边再停21支。
3. `1-5-4`：每边再停20支。
4. 每边合计停47支。
5. 中间剩余111−47×2=17支。

> 说明：本课只转录照片中可辨认并能互相反算的袖片节点，用于个人学习。它仍不是完整生产吓数，也不能直接生成上机程序。

## 本课判断标准

如果看到`X+Y+Z`或`X-Y-Z`时，能说出间隔、每次数量、重复次数，并能用起始针数算到结束针数，就已经掌握本课。
