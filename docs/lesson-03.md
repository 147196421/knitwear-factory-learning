# 第3课：从下往上读前幅、后幅和袖片

## 本课目标

看到一张常见的分片毛衫工艺图时，能够：

1. 分清前幅、后幅和袖片。
2. 找到每片的起底位置。
3. 按常见编织方向，从下往上分段阅读。
4. 知道哪些地方不能只凭轮廓猜工艺。

## 先判断编织方向

常见电脑横机分片毛衫通常从下摆或袖口开始，向肩领或袖山方向编织。因此工艺图一般从织片下方向上读。

这是常见规则，不是绝对规则。横织、局部特殊起织或其他特殊结构可能不同，必须看箭头、起针标注和程序说明。

## 前幅

常见阅读顺序：

1. 起底与开针数。
2. 下摆罗纹。
3. 身段。
4. 夹位／袖窿收针。
5. 肩斜与前领窝。

前领通常比后领深，但不能只看示意轮廓判断实际领深。

## 后幅

下半部分通常与前幅相似，也要从起底、罗纹和身段开始读。上半部分主要看：

- 夹位收针是否与前幅一致。
- 后领窝通常较浅，但以工艺数字为准。
- 左右肩针数、肩斜停针是否能够反算核对。

## 袖片

常见阅读顺序：

1. 袖口开针。
2. 袖口罗纹。
3. 袖身逐段加针。
4. 袖山收针或停针。
5. 袖山顶部剩余针数和结束方式。

袖片顶部叫袖山，不是身片的肩领。袖口到袖身常逐渐变宽，必须逐段核对左右两边总共增加多少针。

## 重要边界

- 肩斜与领窝可能交叉进行，不一定先完成一个再做另一个。
- “停针”和普通收针不是同一动作。
- 工艺单描述生产要求，不是可直接上机的程序。
- 网站图形用于学习阅读顺序，轮廓不按实际比例。

## 本课判断标准

拿到一张常见分片工艺图，能够指着图从下往上讲出“起底—罗纹—身段—夹位／袖山—肩领／袖山顶”，并知道要用针数、转数和动作标注核对，而不是只看外形。
