# 毛织厂电脑横机零基础学习项目

这是一个个人自学用的中文学习项目。学习者从零开始认识毛织工艺单、电脑横机和制版基础，目标是逐步具备看图、验算、试板和独立筹备设备的能力。

课程以一位有经验的毛织工艺老师带初学者的方式编写：先看图和变化，再读公式；每次只学一个概念；每一步都说明“纸上写什么、机器大致做什么、怎样反算检查”。

## 在线学习

[打开公网课程首页](https://147196421.github.io/knitwear-factory-learning/)

仓库内的 `index.html` 是当前可视化课程，手机和电脑浏览器均可打开。

## 部署到自己的服务器

本项目是纯静态网站，可以直接克隆后交给Nginx，也可以使用仓库内的Docker配置：

```bash
git clone https://github.com/147196421/knitwear-factory-learning.git
cd knitwear-factory-learning
docker compose up -d --build
```

默认从服务器的`8080`端口提供网页。自己的域名、HTTPS和更新方法见 `DEPLOY.md`。

## 课程与参考照片的关系

网站不是可直接生产的工艺复刻。7.0版只转录照片中较清楚的开针、衣片总转数和少量宽度数字，生成便于入门理解的示意轮廓；看不清、互相冲突或缺失的收针细节没有擅自补成生产参数。

当前课程够用来建立第一层基础，但不够独立制作上机程序。后续还需要学习纱嘴、度目、罗拉、移圈、摇床、制版软件、试片洗水和异常处理。详细分层方法见 `docs/LEARNING-GUIDE.md`。

## 阅读顺序

1. 打开 `index.html`，按左侧导航学习可视化课程。
2. 打开 `sheet-reading-guide.html`，按两张参考图纸逐区精读并完成袖片反算。
3. 阅读 `docs/lesson-01.md` 至 `docs/lesson-06.md` 复习课程。
4. 查看 `CURRICULUM.md` 了解完整学习路线。
5. 换用其他 AI 时，让它先读 `AI_HANDOFF.md` 和 `AGENTS.md`。

## 文件说明

- `index.html`：课程结构与页面内容
- `sheet-reading-guide.html`：两张参考图纸的零基础逐区精读课
- `sheet-guide.css`：精读课的手机、平板和电脑响应式样式

- `app.js`：逐步动画、计算器、测验与页面交互
- `docs/`：每节课的文字讲义
- `docs/machine-profile.md`：拟购设备档案与采购核对表
- `docs/LEARNING-GUIDE.md`：零基础学习方法、课程边界与2D／3D模拟路线
- `docs/simulator-2-5d.md`：横机四层模拟的动作、限制与验收说明
- `data/`：经过脱敏的练习和设备数据
- `data/reference-sheets-teaching-transcription.json`：两张图纸的脱敏结构化转录、证据等级和教学假设
- `tests/`：教学模型的自动验算
- `Dockerfile`、`compose.yaml`：服务器容器部署
- `DEPLOY.md`：域名、HTTPS和更新说明
- `PROGRESS.md`：学习进度与待办
- `AI_HANDOFF.md`：给接手 AI 的完整项目背景
- `AGENTS.md`：以后更新项目时必须遵守的规则
